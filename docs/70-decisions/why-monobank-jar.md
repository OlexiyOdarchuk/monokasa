# ADR · Чому monobank jar, а не еквайринг

## Контекст

Треба було якось приймати оплату. Варіанти в Україні:
- monobank-jar (банка) з пре-fill `?a=…&t=…`
- monobank Acquiring (повноцінний еквайринг, формуєш платіж через API)
- LiqPay / WayForPay / Fondy / інші
- Stripe (для не-укр карт)

## Рішення

**monobank-jar з prefilled amount + comment.**

## Чому

### Нуль інтеграції з сервером гроші

Jar = просто посилання `https://send.monobank.ua/jar/<id>?a=250&t=abc12345`.
Покупець відкриває → бачить заповнену суму і коментар → тапає
"Оплатити" → гроші падають у банку organizer'а.

Нашому серверу не треба:
- генерувати payment intent
- зберігати картку
- проходити PCI-DSS
- мати акаунт у платіжній установі

### Webhook через Personal API

monobank має `/personal/webhook` — підписка на всі транзакції. Це не
"eвакаринговий" webhook (з payment intent ID), це лише сповіщення
"тобі прийшло X грн з коментарем Y". Ми матчимо коментар з нашим
order code → confirm.

### Комісія = 0 для organizer'а

Банки моно — це особистий рахунок, не еквайринг. Покупець платить як
звичайний transfer. Комісія йому, не organizer'у (часто = 0).

### Поріг суми / верифікація

monobank-jar приймає платежі без жорсткої верифікації покупця для
сум до 5000+ грн, тоді як еквайринг + 3-D Secure збиває частину
покупців-новачків.

### Українська UX

monobank-додаток — найрозповсюдженіший в Україні. Покупець, побачивши
"Сплатити через monobank →", знає що буде далі.

## Trade-offs

| Проблема | Що робимо |
|---|---|
| Покупець може ввести іншу суму | Ловимо amount у webhook; `< total` → відхиляємо, лишається `held`. |
| Покупець може очистити comment | Webhook не зматчить, реconcile теж. Adminдоведеться руками. (Малий ризик — UX моно показує пре-fill.) |
| Webhook не дійшов | `/reconcile` дотягує з виписки. |
| Покупець з-за кордону | jar не доступний; ми не покриваємо цей кейс. |
| Refund | Руками в моно. Нема API. |

## Альтернативи що НЕ обрали

- **monobank Acquiring** — повноцінний еквайринг. Працює, але вимагає
  статусу юр.особи у договорі з моно. Для маленького organizer'а —
  оверкіл.
- **LiqPay / WayForPay** — комісія ~2-3%, складніший webhook, гірша
  UX для українського покупця.
- **Stripe** — для не-укр карт, але українські картки часто не
  проходять; як основний канал — погано.
